# Problem Statement
Develop a C++ program to represent museum rooms as vertices and doorways as edges using an adjacency matrix. 
The program should accept room names and doorway details, display the adjacency matrix, and list the rooms 
directly connected to a selected room.
The program should also allow users to insert a new room with its associated doorways, remove a selected 
doorway between two rooms, and calculate and display the degree of a selected room or its directly connected 
rooms. The updated graph should be displayed after every insertion or deletion operation.
